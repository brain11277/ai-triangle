## The one thing to get right

This is a framework of disciplines a practitioner imposes on **themselves**. Run as a team
assessment it becomes a performance review, and that is fatal rather than merely awkward: the
instrument is self-report, so the moment a score carries consequence, everyone gives the safe
answer instead of the accurate one and every future run is noise.

The session is therefore designed so that **nobody ever says a number**. Three structural
rules:

1. Individual scores are never spoken.
2. Nothing is written on a shared surface.
3. Nothing is collected, including in aggregate.

If you cannot commit to all three, do not run the session. Send people the printable
assessment and let them do it alone, which works perfectly well.

## Read the prebrief first

Send [`manager-prebrief.md`](manager-prebrief.md) **before** the session, not in response to a
request afterwards. Preventing the ask is much easier than declining it, and it offers three
signals that are genuinely more useful to a manager than individual scores: the shape tally,
the failure-modes list, and the commitment-kept rate at 90 days.

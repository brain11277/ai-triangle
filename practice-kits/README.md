# Practice kits

One kit per vertex. Each is a method, a worksheet, a filled-in example, and a one-page
printable.

The microsite says "thirty to sixty minutes once a week." These answer what you open, what
goes in which box, in what order, what happens when the timer goes, and how you know you did
it rather than performed it.

## Which one first

Do not start all three. Start one.

| If this sounds like you | Start with | First session |
|---|---|---|
| My output looks fine and I am not sure I could defend it | [CI of Self](ci-of-self/) | 45 min, this week |
| I have prompts and agents I have never edited | [CI of Your AI Tools](ci-of-your-ai-tools/) | 90 min, this month |
| I am always trying things and never finishing them | [CI of New AI](ci-of-new-ai/) | 60 min, this week |
| All three sound like me | [CI of Self](ci-of-self/) | 45 min, this week |
| I have no idea | Run the [assessment](../assessment/) first | 10 min |

**If everything is low, start with CI of Self.** This is the guidance the assessment itself
gives for a Collapsing shape, and the reason is structural rather than motivational: deciding
which agent to refactor and which new tool to skip are both discernment problems. The other
two vertices are hard to do honestly without the first one running.

## The shape of every kit

| File | What it is |
|---|---|
| `README.md` | The method. Cadence, timeboxes, the passes, what done looks like, the anti-patterns. |
| `worksheet.md` | Fields only. No prose. Fill in 30 to 90 minutes once you have read the method. |
| `worked-example.md` | The same worksheet, filled in from a plausible week, with the uncomfortable entries left uncomfortable. |
| `printable/*.html` | Self-contained one-page card. Opens from a file path, prints from any browser, fetches nothing. |

Two kits also ship a CSV, because the inventory and the ledger are living data that get
sorted and appended to for years. A markdown table stops being maintained at about row twelve.

## A note on the worked examples

In all three, something goes wrong. The self-review finds a claim that was shipped unchecked.
The refactor sprint finds that the highest-value asset was the one the ranking missed. The
scan-and-triage test **fails its success criterion**.

That is deliberate. A worked example where the practice goes smoothly teaches the format and
nothing else, and these practices are only worth the time if they surface things you would
rather not have found.
